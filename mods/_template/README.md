Short description of what the mod does.

## Requirements
- Morrowind (GOTY recommended) — MWSE / OpenMW if needed

## Installation
Copy the contents of this folder (except `source/` and `docs/`) into `Data Files`, then enable `ModName.esp`.

| Folder | Contents |
|---|---|
| `meshes/` | Game-ready `.nif` files |
| `textures/` | Game-ready `.dds` / `.tga` |
| `icons/` | Inventory icons |
| `sound/` | Sound effects |
| `scripts/` | MWSE / OpenMW Lua |
| `source/blender/` | `.blend` work files |
| `source/textures/` | Layered `.xcf` / `.psd` sources |
| `docs/` | Screenshots, notes |
| *(root)* | `ModName.esp` / `.omwaddon` |
